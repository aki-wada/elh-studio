# Quick start / 簡単な手順

1. Extract the downloaded ZIP. Open `app/ELH_Studio.html` in Google Chrome. The application starts in English; select Japanese if needed.
2. Select a folder containing one study. For the main workflow, confirm the suggested PPI, PEI and MRC series. The series must share the same grid; the tool does not correct motion or resample mismatched inputs.
3. Review registration and the four center points (right/left cochlea and vestibule). Correct points that are outside the intended fluid regions.
4. Check each extracted region on the images. Remove unwanted signal, including internal auditory canal fluid, when necessary. Review the enhancement check before interpreting the ratios. If enhancement is insufficient, measurements and export remain blocked until you review the images and record a decision to continue.
5. Save the result ZIP. Reopen it with “Open saved results” to review or continue editing. Check that the ZIP is readable before closing the tab.

The application processes images locally. Links to papers open external websites. Names and notes entered by the user are saved as entered; do not enter identifying information. Treat saved results according to your institution's rules.

## 日本語

1. ZIPを展開し、`app/ELH_Studio.html` をChromeで開きます。初期表示は英語です。必要なら日本語へ変更します。
2. 1検査分のフォルダを選び、PPI・PEI・MRCの割り当てを確認します。同じ画像格子が必要です。体動補正や異なる格子の再標本化は行いません。
3. 位置ずれと左右の蝸牛・前庭の4中心点を確認し、外れていれば修正します。
4. 画像上で抽出範囲を確認し、内耳道の液などの不要な信号を必要に応じて除去します。造影QCも確認します。造影不十分のときは、画像を確認して続行を記録するまで計測表示と保存が保留されます。
5. 結果ZIPを保存します。「保存結果を開く」で再読込・編集継続ができます。タブを閉じる前に保存結果を確認してください。

詳細な対応形式・上限・各画面の操作はPDFマニュアルと追補を参照してください。
